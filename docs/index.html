Why Developers Choose Fortify

🧠

Repo-Aware Context

Scans workspace signature files (`package.json`, `Cargo.toml`, `requirements.txt`, `go.mod`) to automatically tailor system prompts to your project stack.

📎

Smart `@file` References

Attach code files directly in prompt queries with `@path/file.js`. Supports size safety limits and readline Tab-autocomplete.

✏️

Interactive `$EDITOR` Workflow

Draft commit messages with AI, then fine-tune them in your favorite terminal text editor (`code --wait`, `notepad`, `nano`, `vim`) with format validation.

🔌

Pluggable Backends

Switch seamlessly between OpenAI, Anthropic Claude 3.5 Sonnet, or local offline Ollama models with a single config flag.

🧩

Extensible Shortcuts & Rules

Define custom prompt shortcuts (e.g. `@security-check`, `@refactor`) in `.fortify/plugins/` and custom project instructions in `.fortify/rules.md`.

🎨

Rich Terminal TUI

Enjoy diff syntax color highlighting (`+` green, `-` red), border box status alerts, `ora` spinners, and tabular column alignment.
